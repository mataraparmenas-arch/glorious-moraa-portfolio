PORTRAIT
========
Place Glorious Moraa's photograph in this folder as:

    glorious-moraa.jpg

(.jpeg, .png and .webp with the same base name are also detected automatically.)

The site loads it from /images/glorious-moraa.jpg inside the hero portrait panel.
No code changes are needed. Until a photo is present, an elegant placeholder is shown.

Recommended: landscape or portrait, at least 900 px on the long side, face in the upper half.
